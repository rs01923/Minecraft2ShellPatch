# Minecraft2ShellPatch

Client-side Fabric mitigation for [minecraft2shell](https://github.com/bikini/minecraft2shell) Disables FreeType's TrueType hinting interpreter while leaving TTF fonts enabled

# Update (6pm gmt+1)
This has been fixed if you use Minecraft from the official launcher
